Un ensemble est une collection non-ordonnée d’élements.

**Notation:**

- x ∈ X “x est un ´el´ement de X”
- x  /∈ X “x n’est pas un ´el´ement de X”
- {a,b,...,c } l'ensemble courrant des éléments a,b,...,c

> **Exemple**:
· {1,2,3} = {2,1,3} = {1,2,3,2,2, 1}
· N = {0,1,2,3, ... }
· N* = {1,2,3, ... }
